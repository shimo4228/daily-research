# Daily Researchを振り返る

レビューは読み取りと対話です。直近7日を目安に配信記事・保存済み探索素材・実行結果を確認し、
読者に「続きを読みたくなったもの」「新しく考え始めたこと」「繰り返しと感じたもの」を聞きます。
休刊と実行失敗は分け、欠けた記録があれば不明として扱います。

面白い候補が素材にあったのに採用されなかったのか、素材自体に乏しかったのかを確認します。
本人の反応と根拠となる記事・候補をつなぎ、読者紹介・探索経路・編集判断のどこを変えると
よさそうかを提示します。本文から本人の好みを推測して確定しないでください。

記事本数、出典数、repoへの還元数は面白さを測りません。実行時間や失敗件数は運用の状態として
扱い、記事品質の点数に換算しません。採否は本人が判断します。設定・読者紹介・プロンプトの
変更やレビュー状態の保存は、このレビューの完了条件ではありません。

実行物と保存先の確認は[運用ガイド](../../../docs/RUNBOOK.ja.md)を参照してください。
