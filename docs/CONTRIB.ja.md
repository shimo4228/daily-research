# 開発ガイド

現行のデータ契約・CLI呼び出し・保存は`scripts/lib/discovery.py`、起動・認証・ロック・wikiへの引き渡しは`scripts/daily-research.sh`が担当します。
プロンプトは探索・編集の判断を担当します。JSONフィールドを変える場合はschema、検査、描画、プロンプトとの対応、テストを同時に更新してください。

```bash
bats tests
.venv/bin/python -m pytest
```

既存のPythonテスト環境を使います。Claudeはモックし、設定と出力は一時領域へ向けます。
実際の試作は別の確認です。モックテストが通っただけで実試作の成功を報告しないでください。

両工程、通常号・短報号・休刊、出典不足、確認済み／未解決の根拠、不正JSON、認証切れ、タイムアウト、1回再試行、同時実行ロック、同日再実行、試作の隔離、wiki handoffを検証します。
起動引数と入力も確認し、repo文脈が探索へ混入しないことを確かめます。文章の長さは編集上の目安です。

テストから本番へ保存しません。外部テキストとモデルJSONは未信頼データとして扱い、保存操作前に検査します。
モデルのツールはWebSearch/WebFetchのみです。出力パスやシェルコマンドをモデルに選ばせません。
読者の好みは本人の選択で更新し、レビュー自体を変更承認と解釈しません。

両言語の文書を実装と合わせます。旧ADRは日付付き注記で判断の履歴を残し、`graph.jsonld`は凍結します。
個人設定・ログ・調査素材・比較用レポートはコミットへ含めません。
